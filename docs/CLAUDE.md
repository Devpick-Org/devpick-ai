# CLAUDE.md — docs/

이 폴더는 devpick-ai 서버의 운영 및 설계 문서를 보관한다.

---

## 폴더 목적

- 코드만으로 파악하기 어려운 운영 절차, 초기화 방법, 설계 결정을 문서화한다
- 개발자가 로컬 환경 세팅 또는 배포 작업 시 참조하는 실무 문서 모음이다
- 코드 변경 없이 운영 정보를 업데이트할 수 있는 공간이다

---

## 문서 작성 규칙

- 실행 명령은 반드시 코드 블록으로 작성한다
- 전제 조건(환경변수, 사전 설치 등)을 문서 상단에 명시한다
- 일회성 작업인지 반복 실행 가능한 작업인지 명확히 구분한다
- 스크린샷보다 CLI 명령과 예시 출력을 우선한다
- 변경 시 관련 스크립트(`scripts/`)와 내용이 일치하는지 함께 확인한다

---

## 현재 문서

| `MONGO_INIT.md` | MongoDB 컬렉션/인덱스 초기화 절차 | 추가 예정 |

---

## 앞으로 추가할 문서 예시

- `AI_SCHEMA.md` — AI 엔드포인트별 입출력 스키마 명세 (백엔드 서버와 공유용)
- `RAG_DESIGN.md` — RAG 검색 구조, 벡터 인덱스 설계, 컨텍스트 주입 방식
- `EVAL_GUIDE.md` — AI 출력 품질 평가 기준 및 eval 실행 방법
- `PROMPT_RULES.md` — 프롬프트 템플릿 설계 원칙, 변수 규칙, 금지 표현

---

## 주의사항

- 이 폴더에 실행 가능한 코드(`.py`, `.sh` 등)를 넣지 않는다. 스크립트는 `scripts/`에 둔다
- 민감한 정보(API 키, 비밀번호, 실제 DB URL 등)를 문서에 포함하지 않는다
